# GitHub upload checklist

Before pushing:
- Confirm no file exceeds 90 MB.
- Confirm h5ad/h5/npz/npy files are not tracked.
- Confirm docs contain manifests:
  - code_manifest.tsv
  - figure_manifest.tsv
  - table_manifest.tsv
  - input_data_manifest.tsv
  - step_ledger.tsv
- Confirm Step64/65/66/68/73-81B scripts are present.
- Confirm Zenodo will host large data/results.

Suggested repository visibility:
- Use private before submission if manuscript/data are not public.
- Switch to public at acceptance or when journal policy requires.
