# StrokeNiche manuscript code subset: Steps 64/65/66/68/73-81B

This curated GitHub subset contains the code and provenance manifests for the manuscript-relevant steps:

- Step64: state probability and dynamics graph source
- Step65: dynamic genes and regulators
- Step66: perturbation FDR summary
- Step68: validation layer
- Step73: track-specific dynamic marker heatmap
- Step74: WGCNA-style module evidence figure
- Step75: spatial marker/module atlas
- Step76: latent-state pseudo-energy landscape
- Step77: latent state-probability landscape
- Step78: virtual perturbation response landscape
- Step79: timepoint progression atlas
- Step80: candidate perturbation-axis expression dotplot
- Step81B: surrogate feature-response audit

Large processed AnnData files, large figure files, source data tables and complete result bundles are deposited separately on Zenodo. This GitHub repository contains code, manifests, lightweight reports and reproducibility instructions.

Important interpretation note:
Virtual perturbation response analyses are computational surrogate analyses. They should not be interpreted as wet-lab knockout/blockade experiments, causal ligand-receptor validation, physical energy landscapes or observed cell-state transitions.
